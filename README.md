Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json

    "chas-elite-prep-mcp": {
      "command": "uvx",
      "args": ["chas-elite-prep-mcp"]
    }
  }
}
```

Or: `pip install chas-elite-prep-mcp` then run the `chas-elite-prep-mcp` command (stdio transport).
